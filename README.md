🚀 Social Media Sentiment Analysis
Analyzing user sentiments from Twitter and Instagram to uncover real-time market trends and engagement patterns.

📌 Overview
This project focuses on extracting and analyzing user sentiment from social media platforms to:

✅ Classify user sentiments into Positive, Neutral, and Negative categories

🔍 Identify trending topics and engagement patterns

💡 Deliver actionable insights for businesses to enhance customer experience

🛠️ Tools & Technologies
Programming Language: Python

Libraries: pandas, TextBlob, seaborn, matplotlib, WordCloud

Data Processing: Regex, missing value handling

NLP Techniques:

Sentiment Analysis

Hashtag Extraction

Visualization:

Interactive Plots

Word Clouds

Temporal Trend Analysis

🔍 Key Insights
📈 Positive posts saw 20% higher engagement than negative ones

🕑 Peak activity observed daily between 2–4 PM, showing higher sentiment fluctuations

🏷️ Top hashtags like #CustomerExperience and #TechNews contributed significantly to positive sentiment spikes
